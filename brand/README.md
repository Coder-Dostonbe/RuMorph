# Tilsim — logo

Konsepsiya: o'zbek me'morchiligidagi sakkiz qirrali girih yulduzi (tilsim shakli) va markazida kirill **"Я"** harfi.
Harf shrift emas, chiziqlardan yasalgan. Shuning uchun SVG hech qaysi shriftga bog'liq emas.

| Fayl | Variant |
| ---- | ------- |
| `tilsim-a.svg` | A — indigo fon, to'ldirilgan firuza yulduz, indigo harf. Kichik o'lchamda eng aniq ko'rinadi. |
| `tilsim-b.svg` | B — indigo fon, chiziqli firuza yulduz, oltin halqa, oq harf. Nafisroq, lekin 16–24 px da detallar yo'qoladi. |
| `tilsim-c.svg` | C — och (krem) fon, indigo yulduz, firuza harf. |
| `tilsim-variantlar.png` | Uchala variant 256, 48 va 24 px da. |

Ranglar: indigo `#1A1F4E`, firuza `#22A6A1`, oltin `#E0B04F`, krem `#F5F1E6`.

Tanlangan variantdan barcha ikonkalar `npx tauri icon brand/<fayl>.svg` bilan yaratiladi
(Windows `.ico` va Android adaptive icon). Android uchun old qatlam markazdagi xavfsiz zonaga
sig'adigan qilib alohida tayyorlanadi (8-bosqich).
